Skills in detail

Training and learning design

Self-paced and instructor-led courses for beginners through to technical teams, and the Moodle platforms that deliver them, set up for geospatial learning.

Moodle administration, OpenLearn Create, curriculum design, facilitation

Data platforms and governance

Collecting, preparing and publishing spatial data, and setting up and supporting the systems that hold it, with the metadata and access rules that keep it trustworthy.

Mobile data collection, GeoNode, PostGIS, QGIS Server, Docker, ISO metadata

Maps and analysis

QGIS, ArcGIS Pro, Digital Earth Africa, Python, SQL
